GATEFRONT — PLAYABLE PROTOTYPE

Open index.html in a browser to inspect the files, or serve this folder with any simple web server.
On Android Chrome, the hosted version can be installed to the home screen as an app.

Controls:
- Drag left and right.
- Shooting is automatic.
- Pass through green gates to gain troops or power.
- Avoid red gates and defeat the boss.

This prototype is intentionally self-contained and uses no external libraries.
